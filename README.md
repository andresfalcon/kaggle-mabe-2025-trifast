# MABe 2025 – TriFast Baseline

Repositorio para la competencia Kaggle **MABe Mouse Behavior Detection 2025**.  

## Estructura
- `src/mabe/` → Código fuente (modelos, data loaders, utils).
- `configs/` → Configuraciones (`config_local.toml`, `config_kaggle.toml`).
- `tests/` → Tests unitarios básicos.
- `C:/data/mabe/` → Datos locales (no versionados).
- `.venv/` → Entorno virtual (no versionado).
